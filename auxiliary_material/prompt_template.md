This document contains the template used for GPT. The base version is adapted to sharks; when referring to a ray, the term “Shark” should be replaced with “Stingray.” After these instructions, the specific details of the species are provided, corresponding to the first candidate prompt in each case.


I’m creating prompts for CLIP to identify species. I have an expert knowledge base that defines various characteristics of the species, and I want you to help me generate several versions following these instructions:
1. Start all prompts with the word Shark, for example: Shark with a…
2. Do not add any information beyond what I provide.
3. Randomly include or exclude characteristics of the animal to create versions that emphasize different traits.
4. Rephrase words without changing their meaning.
5. Return the result as a Python list, like this: ["Shark...", "Shark..."]
